# Changelog

## 0.1.0 — 2026-10-07

- Initial read-only CLI with offline, canonical resolved, and live status modes.
- Diagnostics for port conflicts, mount paths, missing interpolation variables, dependencies, named resources, and image pinning.
- Text and versioned JSON reports with configurable failure thresholds.
- Sensitive field values and Docker stderr omitted from reports.
- Healthy and deliberately broken example stacks, regression tests, and contributor templates.
